# YiGo M4（人机对弈）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GameController 对弈状态机（Idle/HumanTurn/EngineThinking/GameOver）+ 引擎 genmove 落子 + 让子/贴目对局设置 + 连续虚手终局判定，交付可人机对弈的 `yigo`。

**Architecture:** 新增 `src/app/GameController`（QtCore-only，编入 yigo_core 以离线单测）：持有 Game + EngineProcess 引用，按执方配置（人/AI）驱动轮转。引擎落子经 `genmove`（GTP 标准命令，复用 M3 EngineProcess 串行队列）；GameController 不改 Game 树结构，走既有 `Game::play`。让子 = 根节点 `addSetupStone`（M1 已支持 AB 摆子路径）+ `RulesConfig.handicap`。终局 = 连续两次 pass 或引擎 resign，终局分数用本地 `Rules::score`（中国/日本双规则，M1 已交付；引擎 final_score 为可选复核，spec §3「终局死活判定依赖引擎」以 final_score 优先级高于本地分）。UI 侧 MainWindow 增「对局」设置（执方/让子/贴目），状态栏显示 Phase。

**Tech Stack:** C++17, Qt 5.11.3 (QtCore; QtWidgets for dialogs), CMake 3.22, Ninja, QtTest（GameController 用 fake_engine.sh 离线测 genmove；不依赖真引擎）

**Spec:** `docs/superpowers/specs/2026-09-21-yigo-architecture-design.md`（§3 Rules/G handicaps、§5 GameController、§6 错误处理、§8 里程碑 M4）

```cpp
QPoint Game::handicapPoint(int boardSize, int n) {
    if (n < 0) return QPoint(-1, -1);
    // corner order: R-bottom, L-bottom, L-top, R-top, tengen, then sides
    QVector<QPoint> pts;
    if (boardSize == 19) pts = {{15,3},{3,3},{3,15},{15,15},{9,9},{9,3},{3,9},{15,9},{9,15}};
    else if (boardSize == 13) pts = {{9,3},{3,3},{3,9},{9,9},{6,6},{6,3},{3,6},{9,6},{6,9}};
    else if (boardSize == 9) pts = {{6,2},{2,2},{2,6},{6,6},{4,4},{4,2},{2,4},{6,4},{4,6}};
    else return QPoint(-1, -1);
    // valid handicap counts: 2..9 (and tengen only for odd counts >=5)
    if (n >= pts.size()) return QPoint(-1, -1);
    if (n >= 4 && n % 2 == 0) return QPoint(-1, -1);   // even counts skip tengen
    return pts[n];
}

void Game::setupHandicap(int stones) {
    m_setupStones.clear();
    int applied = 0;
    for (int n = 0; n < stones; ++n) {
        const QPoint p = handicapPoint(boardSize(), n);
        if (p.x() < 0) break;
        m_setupStones.append(qMakePair(p, Stone::Black));
        ++applied;
    }
    m_cfg.handicap = applied;
    rebuildBoard();
}
```

（注意：`m_cfg` 是 const 值成员吗——检查 M1 声明 `RulesConfig m_cfg;` 非 const，可直接赋值；若编译报 const 则在 setupHandicap 内改用局部副本赋值。）

  ```cpp
  class GameController : public QObject {
      Q_OBJECT
  public:
      enum class Phase { Idle, HumanTurn, EngineThinking, GameOver };
      explicit GameController(QObject* parent = nullptr);
      void newGame(const GameSetup& setup);   // 创建 Game、应用让子、进入首手
      Game* game() const { return m_game; }
      Phase phase() const { return m_phase; }
      Stone engineColor() const { return m_engineColor; }
      void attachEngine(EngineProcess* engine);   // 不获得所有权
      void detachEngine();
      Stone winner() const { return m_winner; }       // GameOver 时有效
      QString endReason() const { return m_endReason; } // "resign"/"two passes"/"score"
  public slots:
      // 人类落子（含 pass）；非法时发 moveRejected
      bool humanPlay(QPoint pos);
      void resign();          // 当前方认输
  signals:
      void phaseChanged(GameController::Phase phase);
      void moveRejected(const QString& reason);
      void gameOver(Stone winner, const QString& reason);
  private:
      void advanceTurn();     // 根据当前执方与配置驱动轮转
      void requestEngineMove();
      Stone m_engineColor = Stone::Empty;
      Game* m_game = nullptr;
      GameSetup m_setup;
      Phase m_phase = Phase::Idle;
      Stone m_winner = Stone::Empty;
      QString m_endReason;
      bool m_movePending = false;   // genmove 已发出未返回
  };
  ```
  状态机规则：
  - newGame：`m_game = new Game(size, cfg)`；handicap>0 时 `setupHandicap`；Komi 写入 RulesConfig；若当前执方是 AI → EngineThinking 并发 genmove，否则 HumanTurn
  - humanPlay：仅 HumanTurn 且执方为 Human 时接受；落子成功 → advanceTurn
  - genmove 响应（queryFinished）：解析 "D4"/"pass"/"resign"（AnalysisParser::parseMove 已有：pass=(-1,-1) resign=(-2,-2)）；`Game::play` 落子；pass 后连续两次 pass → GameOver（本地 Rules::score 计分，winner 按 blackMargin）；resign → GameOver 对方胜
  - crashed / errorOccurred：m_movePending 清除；若原来在 EngineThinking → 回退 HumanTurn（人类可继续，引擎离线）
  - 双 AI：advanceTurn 检测下一手仍是 AI 且引擎在线 → 继续 genmove（队列串行天然防重叠）
  - 防重入：m_movePending=true 期间 humanPlay/genmove 请求均拒绝

```cpp
void GameController::newGame(const GameSetup& setup) {
    delete m_game;
    m_setup = setup;
    RulesConfig cfg;
    cfg.komi = setup.komi;
    cfg.handicap = setup.handicap;
    m_game = new Game(setup.boardSize, cfg);
    if (setup.handicap > 0) m_game->setupHandicap(setup.handicap);
    m_winner = Stone::Empty;
    m_endReason.clear();
    m_movePending = false;
    m_engineColor = Stone::Empty;
    if (setup.black.kind == PlayerConfig::AI) m_engineColor = Stone::Black;
    else if (setup.white.kind == PlayerConfig::AI) m_engineColor = Stone::White;
    // 双 AI: engineColor 语义为"引擎执任意 AI 方"——用 Empty 表示双侧
    if (setup.black.kind == PlayerConfig::AI && setup.white.kind == PlayerConfig::AI)
        m_engineColor = Stone::Empty;
    m_phase = Phase::Idle;
    Q_EMIT phaseChanged(m_phase);
    advanceTurn();
}

void GameController::advanceTurn() {
    if (!m_game || m_phase == Phase::GameOver) return;
    const Stone toMove = m_game->nextToPlay();
    const PlayerConfig::Kind kind =
        toMove == Stone::Black ? m_setup.black.kind : m_setup.white.kind;
    if (kind == PlayerConfig::AI && m_engine && m_engine->isRunning()) {
        m_phase = Phase::EngineThinking;
        Q_EMIT phaseChanged(m_phase);
        requestEngineMove();
    } else {
        m_phase = Phase::HumanTurn;
        Q_EMIT phaseChanged(m_phase);
    }
}

void GameController::requestEngineMove() {
    if (m_movePending) return;
    m_movePending = true;
    // sync position then genmove (M3 analyzePosition drains queue then streams;
    // for genmove we reuse the same queue mechanism via a public API)
    // —— 裁决：EngineProcess 需要新增 genMove(AnalysisQuery 风格) 接口:
    //    query(genmove) 一次一行命令即可；位置同步命令在 genmove 前逐条发送。
    //    为避免 M3 queue 语义重写，GameController 直接发:
    //    positionCommands 逐条 query()，最后一条后 query(genmove)。
    //    响应配对：queryFinished(id) 无法区分——用 id 计数器在 controller 侧
    //    记录 genmove 的 id（EngineProcess 透传 id）。
```

```cpp
void GameController::onQueryFinished(quint64 id, bool success, const QString& body) {
    if (id != m_genmoveId || !m_movePending) return;
    m_movePending = false;
    if (!success) { engineFailed(QStringLiteral("genmove error")); return; }
    const QPoint mv = AnalysisParser::parseMove(body, m_game->boardSize());
    if (mv == QPoint(-2, -2)) {   // resign
        endGame(Board::opponent(m_game->nextToPlay()), QStringLiteral("resign"));
        return;
    }
    const Stone color = m_game->nextToPlay();
    if (mv.x() < 0) {   // pass
        m_game->play(QPoint(-1, -1), color);
        if (m_lastWasPass) { scoreEnd(); return; }
        m_lastWasPass = true;
    } else if (m_game->play(mv, color)) {
        m_lastWasPass = false;
    } else {
        // genmove 点非法：引擎 bug 容错，重试（review focus 1）
        if (++m_genmoveRetries < 3) { requestEngineMove(); return; }
        endGame(Stone::Empty, QStringLiteral("engine error"));
        return;
    }
    advanceTurn();
}
```

```cpp
bool GameController::undoInPlay() {
    if (!m_game || m_phase != Phase::HumanTurn || m_movePending) return false;
    // undo until we are before the human's last move: step back over AI+human
    const Stone humanColor = /* 非引擎执方; 双AI时只退一手 */;
    int steps = 0;
    MoveNode* n = m_game->currentNode();
    while (n->parent) {
        n = n->parent;
        ++steps;
        if (n->color == Stone::Empty || n == m_game->tree().root()) break;
        // 双 AI: 1 步；人机: 退过 AI 手 + 人手 = 2 步
        if (m_setup.black.kind == PlayerConfig::AI && m_setup.white.kind == PlayerConfig::AI)
            break;
        if (n->color != humanColor && steps >= 2) break;
    }
    for (int i = 0; i < steps; ++i) m_game->undo();
    advanceTurn();   // 重新进入 HumanTurn
    return true;
}
```
