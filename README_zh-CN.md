# 弈境 (YiGo)

[English](README.md) | 简体中文

## 项目简介

**弈境（YiGo）** 是一款基于纯 Qt C++ 开发的跨平台围棋 AI 对弈与复盘工具，功能对标 Katrain。全程采用原生 Qt 开发，无 Python 依赖，启动更快、占用更低、跨平台体验更统一。支持 Windows、macOS、Linux 全平台，面向围棋爱好者、复盘学习者与专业棋手，提供稳定、轻量、高性能的 AI 分析与棋谱管理能力。

## 核心特性

- **纯 Qt 原生开发**：C++ Qt 5.11 构建，轻量、高效、无脚本依赖
- **全平台支持**：Windows / macOS / Linux 统一体验
- **标准 AI 引擎对接**：原生 GTP 协议支持 KataGo / Leela Zero
- **专业复盘能力**：形势判断、胜率曲线、招法分析、变化推演
- **完整 SGF 支持**：棋谱打开、保存、编辑、分支管理、对局回放
- **高 DPI 适配**：高分屏清晰渲染，界面细腻无模糊

## 技术栈

- **框架**：Qt 5.11（Widgets / Core / Concurrent / Network / Svg）
- **语言**：C++17
- **构建系统**：CMake
- **AI 协议**：GTP（Go Text Protocol）
- **支持的引擎**：KataGo、Leela Zero

## 适用场景

- 围棋日常对弈、自我训练
- 对局复盘、AI 纠错与招法优化
- 棋谱整理、教学演示、变化研究
